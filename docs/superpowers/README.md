# Design and Implementation Records

> **Status:** active

> **Reviewed:** 2026-09-24

This folder preserves design specs and implementation plans written while
shaping the thesis workspace. Use them to understand why earlier decisions
were made; they are records, not current operating instructions unless linked
from an active guide.

- `specs/`: dated design decisions and intended behavior.
- `plans/`: step-by-step implementation records.
- [Current Technion XeLaTeX migration plan](plans/2026-09-20-technion-xelatex-migration.md):
  active plan for replacing the generic LaTeX scaffold.
- [Template audit](../../research-context/technion-template-audit-2026-09-20.md):
  observed state that motivated the migration plan.

Completed or superseded records use the `historical` status. Keep the root
[workspace guide](../../README.md) and area READMEs as the current navigation
and workflow guidance.
