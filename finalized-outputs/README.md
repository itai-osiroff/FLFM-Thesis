# Finalized Outputs

Curated outputs that are candidates for thesis inclusion.

- `figures-final/`: Polished exported figures.
- `figures-source/`: Editable source files for figures.
- `tables-final/`: Final or near-final thesis tables.

When a figure or table is copied into `overleaf/`, add a matching provenance
record under `research-context/result-provenance/`.
