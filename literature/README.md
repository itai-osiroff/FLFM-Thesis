# Literature

External resources that support the thesis.

- `articles/`: Journal papers, conference papers, and preprints.
- `books/`: Books and long-form references.
- `thesis-examples/`: Other theses used for structure, tone, and wording.
- `notes/`: Reading notes written by the author.

Prefer one focused note per important paper. Notes should capture the paper's
claim, relevance to the thesis, useful equations or figures, and how it may be
cited.
