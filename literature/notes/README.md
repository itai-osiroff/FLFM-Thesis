# Literature Notes

> **Status:** active
>
> **Reviewed:** 2026-09-24

These author-written notes capture useful parts of external sources for thesis
work. They are navigation and synthesis aids; consult the cited source before
relying on a quotation, equation, figure, or scientific claim.

- [Reading note template](reading-note-template.md): structure for new notes.
- Paper and book notes: record the source's claim, relevance, useful details,
  limitations, and possible role in the thesis.
- Thesis-example notes: summarize presentation or structure lessons without
  treating the example as a source of thesis content.
- [Targeted literature gap fill](targeted-literature-gap-fill-2026-07-17.md):
  search summary for selected literature gaps.

Link notes to the [literature index](../README.md) and update the
[claim tracker](../../planning/claim-tracker.md) when a source supports a
specific thesis claim.
