# Thesis Examples

> **Status:** active
>
> **Reviewed:** 2026-09-26

This area holds comparative thesis examples and notes about how they may inform
the presentation of this thesis. Use examples to study structure, completeness,
and scholarly communication; do not copy their prose or treat them as evidence
for this thesis's scientific claims.

- [Hadar reference standard](hadar-reference-standard.md): explains why Hadar's
  thesis is the primary comparative reference and how to use it.
- [Technical-writing source register](../writing-guidance/source-register.md):
  Kellman, Eckert, and Yeh as supplemental modelling/calibration exemplars,
  with explicit verification limits and optional local-copy guidance.
- `Hadar's Thesis/`: optional local clone of the upstream thesis repository.
  Git ignores this folder; the tracked reference note and upstream record
  document its source and role.

For thesis-specific writing rules, see the [writing standard](../../planning/writing-standard.md).
