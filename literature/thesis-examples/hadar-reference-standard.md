# Hadar Thesis: Primary Comparative Reference

Hadar's thesis is this project's primary comparative thesis reference. It is
especially informative because it was written in the same research field and
under the same supervisor. Use it to calibrate scholarly communication and
supervisor-facing completeness, not as a source of content for this thesis.

## Permitted uses

- Chapter pacing: establish the problem and prior work, define the model or
  method, present evidence, then interpret limitations.
- Scientific tone: direct technical definitions, explicit transitions, bounded
  claims, and limitations stated alongside positive findings.
- Figure design: introduce the system/model before results; make each figure
  answer a stated question; use captions that state the data, condition,
  comparison, and takeaway.
- Thesis completeness: use the English/Hebrew organization, front matter, and
  appendices as a quality checklist while the active project uses the maintained
  Technion template.

## Boundaries

Do not copy prose, equations, scientific claims, figures, data, bibliography
entries, or interpretations. Every active-thesis claim and asset must remain
supported by this project's own literature and provenance records.

The source project is a legacy LaTeX reference, not the active template. Its
current MiKTeX/XeLaTeX build requires compatibility work for its Babel/David CLM
font stack; see `planning/upstreams.md` for details.
